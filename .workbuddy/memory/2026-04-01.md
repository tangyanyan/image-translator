## 图片英文识别翻译工具

### 最终方案 (v1.0)
- **OCR**: OCR.space API (Engine 2 高精度，个人 Key: `K83524497588957`)
- **翻译**: MyMemory 翻译 API（免费，浏览器端可用）

### 技术决策记录
1. **OCR.space → 百度 OCR**: 国内网络访问更稳定
2. **MyMemory 翻译**: 浏览器端无 CORS 限制，可用
3. **百度翻译 API**: 有 CORS 限制，浏览器端无法直接调用
4. **百度图片翻译 API**: 需要对二进制图片数据计算 MD5 签名，浏览器端实现复杂且有性能问题
5. **SheetJS XLSX 导出**: CDN 加载失败(ERR_CONNECTION_CLOSED)，已移除该功能
